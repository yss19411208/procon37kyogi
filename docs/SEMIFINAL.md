## 2. この盤で予想される展開

- **混雑1／渋滞2 は異常に低い。** 交通量は「全チームの滞在歩数 ÷ チーム数」なので、平均1歩で混雑（2歩）、2歩で渋滞（4歩）。平地は2歩なので、**人が通った道路は2日目以降ずっと平地より劣化**します。
  - **初日は全道路が順調（1歩）。** 初日だけ道路が速いので、遠くの系列はこの日に取るのが得です。
  - **誰も通らない道路は順調のまま**残ります。渋滞予測（`congestion_risk`）が基準値から計算しているので、そこは読めています。
- **補給車は1台。** 測定で2台は負けました（149 対 146）。
- **日別108は取れる見込み。** 過去の24x24は系列20・巡回4台で満点が構造的に無理でしたが、準決勝は**系列18**なので1台あたり0.5系列ぶん楽です。上位も満点で並ぶはずなので、**勝負は玉数**になります。

## 4. 試合中に見る2行

1日の終わりにこれが出ます。

```
補給: 5回 / 合計248燃料（1回平均50 / 20以下2回） → 1位に並ぶ目安は1日80燃料（1台20×4台）
明日の朝の燃料 [80, 22, 0, 1] ← **2台が動けません**
```

- **「合計◯燃料」が80に届いているか。** 届かない日があれば、そこが削られた玉数です。
- **「◯台が動けません」が出た日は、翌日が壊れます。** 準決勝32x32の3日目がまさにそれで、玉が他の日の3分の2しかありませんでした。出たらログを残してください。

ほかに出る行:

```
探索: 親◯手 / 磨き◯手（当たり◯ / 出発点◯か所） / 子から◯案 / 候補◯件 / ◯秒で初回提出
この日の上限 玉◯（満タンなら◯ / いまの燃料で◯ / 在庫◯ → ◯が縛っています） → 取れたのは◯（◯%）
⚠ 設計が失敗しました: ...
```

最後の行が出たら、設計が黙って消えているサインです（今日それで順位合計が3落ちていたのを見つけました）。
