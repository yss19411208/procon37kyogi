# 2台のPCをつないで練習する

**この紙だけで終わるように書いてあります。** 上から順にやってください。

---

## いちばん先に読むところ（3分で動かす）

**LANケーブルは、いちばん難しいやり方です。** うまくいかないときは
下の「やり方1」にしてください。**設定が1つも要りません。**

### やり方1: 同じWi-Fi（または同じルーター）につなぐ ← おすすめ

2台を**同じWi-Fiにつなぐだけ**です。ケーブルも固定IPも要りません。
学校のWi-Fiでも、スマホのテザリングでも、家のルーターでもできます。

1. 2台とも同じWi-Fiにつなぐ
2. **PC-A**（サーバー役）で `python main.py` → メニュー **14番**
   → 全部 Enter
3. 画面に出る「別のPCからは」の行を**そのまま**メモする
   （例 `http://192.168.1.23:8080`）
4. ファイアウォールの許可を聞かれたら「**はい**」。青い画面が出たら
   **プライベートとパブリックの両方にチェック**
5. **PC-B**（選手役）で `python main.py` → メニュー **20番**
   → さっきのURLと `team1` を入れる → 「つながりました」が出たら成功
6. 成功したら PC-B でメニュー **8番**。同じURLとトークンを入れる

> **学校のWi-Fiで駄目なとき。** 来客用ネットワークは、つないだ機器
> どうしの通信を止めていることがあります。そのときは**スマホの
> テザリング**に2台ともつなぐと、ほぼ必ず通ります。

### やり方2: LANケーブルで直結する

ルーターがないときだけ使います。**Windowsの設定が要るので、
やり方1より手間がかかります。** 2章から順に読んでください。

### どちらでも、詰まったらこの1画面

メニュー **21番 → 6番「いまの状態をまとめて見る」**。アドレス・
ファイアウォール・待ち受けポート・ネットワークの種類を1画面で出します。

---

## 以下はLANケーブルで直結するときの手順

途中で分からなくなったら、メニュー **21番「LAN対戦の準備」→ 6番
「いまの状態をまとめて見る」** を押してください。アドレス・
ファイアウォール・待ち受けポート・ネットワークの種類を1画面で出します。
この紙そのものも **21番 → 7番** で読めます。

---

## 0. 用意するもの

- PCが2台（どちらもWindowsを想定）
- **LANケーブル1本**。いまのPCは自動で向きを合わせるので、
  **ふつうのストレートケーブルで大丈夫**です（クロスは不要）。
- どちらのPCにも `hexaudon` のフォルダを置いておきます。

**役割を決めます。**

| 役 | やること |
|---|---|
| **サーバー役** | 問題を配り、答えを受ける。メニュー **14番** |
| **選手役** | 解いて出す。メニュー **8番** |

以下、サーバー役を **PC-A**、選手役を **PC-B** と呼びます。
1台で両方やる練習（メニュー10番など）はケーブルも設定も要りません。

---

## 1. ケーブルをつなぐ

2台を直接つなぎます。ハブやスイッチがあるなら、両方をそこに
つないでも同じです。

つないだ直後、Windowsは「**識別されていないネットワーク**」と
出すことがあります。**これは正常です。** 家庭のルーターのような
「IPアドレスを配る係（DHCP）」がいないので、Windowsが自分で
`169.254.x.x` という仮のアドレスを付けるまで**40〜60秒ほどかかります**。

> **ここで慌てないこと。** 1分待ってから次に進んでください。

---

## 2. アドレスを決める（いちばん詰まるところ）

### 方法A: 待つだけ（おすすめ・設定不要）

1分待って、両方のPCで

```
ipconfig
```

を実行します。`イーサネット` の `IPv4 アドレス` が

```
169.254.□□.□□
```

になっていれば、**そのままで通じます**。PC-Aのその数字を覚えて
ください。

### 方法B: 固定IPを入れる（Aで駄目なとき・確実）

片方だけ `169.254` にならない、あるいは待っても出ないときは、
手で入れます。**2台とも**やります。

1. `Windows + R` → `ncpa.cpl` と入力して Enter
2. **イーサネット** を右クリック → **プロパティ**
3. 「インターネット プロトコル バージョン 4 (TCP/IPv4)」を選び
   **プロパティ**
4. 「**次の IP アドレスを使う**」を選び、下のように入れます

| | PC-A（サーバー役） | PC-B（選手役） |
|---|---|---|
| IPアドレス | `192.168.50.1` | `192.168.50.2` |
| サブネットマスク | `255.255.255.0` | `255.255.255.0` |
| デフォルトゲートウェイ | **空のまま** | **空のまま** |
| DNS | **空のまま** | **空のまま** |

5. OK → OK で閉じます。

**画面をたどるのが面倒なときは、PowerShellを「管理者として実行」して
この1行でも同じことができます**（PC-Aなら `.1`、PC-Bなら `.2`）。

```
New-NetIPAddress -InterfaceAlias "イーサネット" -IPAddress 192.168.50.1 -PrefixLength 24
```

元に戻すとき（自動取得にする）:

```
Set-NetIPInterface -InterfaceAlias "イーサネット" -Dhcp Enabled
```

`"イーサネット"` の名前が違うときは `Get-NetAdapter` で確かめます。

> **ゲートウェイを空にするのが大事です。** 入れると Windows が
> 「この線からインターネットに出る」と思い込み、無線のほうが
> 使われなくなります。

### 無線は切る

**試合中・練習中は Wi-Fi を切ってください。** 有線と無線の両方が
生きていると、Windowsはどちらを使うか迷い、`ping` は通るのに
つながらないという分かりにくい状態になります。

```
Windows + A → Wi-Fi のタイルを押して切る
```

---

## 3. PC-A（サーバー役）でサーバーを立てる

1. `hexaudon` のフォルダで起動します（`python main.py` または
   `起動.bat`）。
2. メニューの **14番「練習用サーバーを立てる」** を選びます。
3. 聞かれる内容はそのまま Enter で進めて大丈夫です
   （試合の条件・チーム数・日数・回答時間・乱数の種）。
4. 立ち上がると、こう出ます。

```
  サーバーを起動しました。
    このPCから  : http://127.0.0.1:8080

  別のPCからは、下のどれかで繋がります（上から試してください）:
    http://169.254.12.34:8080
    http://192.168.50.1:8080
```

**この「別のPCからは」の行をメモします。** PC-Bで入れるのはこれです。

5. 続けて「**ファイアウォールでこのポートの受信を許可しますか**」と
   聞かれます。**「はい」を選んでください。**
   - Windowsが「このアプリの機能を許可する」という青い画面を出したら、
     **「プライベート ネットワーク」と「パブリック ネットワーク」の
     両方にチェック**を入れて許可します。
   - 「識別されていないネットワーク」は Windows から見ると
     **パブリック**扱いです。パブリックにチェックを入れないと、
     ここで必ず止まります。
   - 管理者の確認（UAC）が出たら「はい」。
   - 失敗したと出たときは、PC-Aで**管理者として** PowerShell を開き、
     次の1行を実行します（`8080` は実際のポート番号に）。

```
New-NetFirewallRule -DisplayName "procon8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
```

6. サーバーが本当に外からの受信を待っているか、PC-Aで確かめます。

```
netstat -ano | findstr :8080
```

- `0.0.0.0:8080` と出ていれば **外から受けられます**（正解）
- `127.0.0.1:8080` しか出ないときは自分専用です。14番で立て直してください。

---

## 4. PC-B（選手役）からつなぐ

1. まず**届くかだけ**を確かめます。PC-Bで:

```
ping 169.254.12.34
```

（PC-Aのアドレスに置き換えます）

- 応答が返る → 5へ
- 返らない → **2章のアドレス**に戻ります。ケーブルの差し直しも。

2. 次にポートまで届くかを確かめます。PC-Bで:

```
curl http://169.254.12.34:8080/
```

- 何か文字が返る（エラーの文字でもよい）→ **通っています**
- 「接続できません」→ **3章のファイアウォール**です

3. `hexaudon` を起動し、メニュー **20番「通信だけ確認する」** を
   選びます。URLとトークンを入れると、どこで失敗しているかを
   そのまま教えます。
   - URL: `http://169.254.12.34:8080`
   - トークン: `team1`（14番で立てたサーバーは `team1`〜`team10`）

4. 通ったら、メニュー **8番「本番どおりに1試合する」** に、同じ
   URLとトークンを入れます。

---

## 5. それでも駄目なとき（よくある順）

| 症状 | 原因 | 直し方 |
|---|---|---|
| `ping` が通らない | アドレスが別の網 | 2章B（両方に固定IP、マスク255.255.255.0） |
| `ping` は通るがポートが駄目 | ファイアウォール | 3章5（**パブリックにもチェック**） |
| `netstat` に `127.0.0.1` だけ | サーバーが自分専用 | 14番で立て直す |
| 無線を切ると通る | 経路の取り違え | 試合中は Wi-Fi を切る |
| ときどき切れる | 省電力でLANが寝る | デバイスマネージャー → イーサネット → 電源の管理 → 「電力の節約のために…」のチェックを**外す** |
| ウイルス対策ソフトを入れている | 独自の壁 | そのソフトでポート8080の受信を許可、または一時停止 |
| `169.254` 同士なのに通らない | 1分待っていない | もう1分待って `ipconfig` を見直す |

**確認の順番を変えないでください。** 上から順に潰すのがいちばん速いです
（`ping` → `curl` → 20番）。

---

## 6. 覚え書き

- サーバー役のPCは**解きません**。14番を出したまま置いておきます。
- 選手役が複数台あるときは、トークンを `team1` `team2` … と
  **1台ずつ変えます**。同じトークンを2台で使うと混ざります。
- 試合が終わったら、PC-Aで「ファイアウォールの許可を元に戻しますか」に
  **はい**と答えておくと、入れた穴が閉じます。
- ポート番号は14番が表示したものを使います（既定は8080ですが、
  使われていると別の番号になります）。
